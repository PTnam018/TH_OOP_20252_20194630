Question: Alternatively, to compare items in the cart, instead of using Comparator, we can use the
Comparable interface and override the compareTo()method. You can refer to the Java docs to see
the information of this interface.
Suppose we are taking this Comparable interface approach.
- What class should implement the Comparable interface?
    Answer: Lớp Media nên implement interface Comparable<Media> vì tất cả các loại media như Book, CompactDisc, DigitalVideoDisc đều kế thừa từ lớp này.
            Khi đó, mọi đối tượng media đều có thể được sắp xếp bằng phương thức Collections.sort()
- In those classes, how should you implement the compareTo()method be to reflect the ordering that we
want?
    Answer:Để phản ánh quy tắc sắp xếp “theo title rồi đến cost”, phương thức compareTo() cần:
            So sánh title theo thứ tự alphabet trước.
            Nếu hai media có cùng title thì so sánh cost theo thứ tự giảm dần.
- Can we have two ordering rules of the item (by title then cost and by cost then title) if we use this
Comparable interface approach?
    Answer:Không.
            Interface Comparable chỉ cho phép định nghĩa một “natural ordering” thông qua phương thức compareTo(). 
            Vì vậy mỗi lớp chỉ có một cách sắp xếp mặc định.
            Do đó, nếu dùng Comparable, ta chỉ có thể chọn một trong hai:
            sắp xếp theo title rồi cost
            hoặc
            sắp xếp theo cost rồi title.
            Nếu chương trình cần nhiều cách sắp xếp khác nhau thì Comparator sẽ phù hợp hơn vì có thể tạo nhiều comparator riêng biệt cho từng quy tắc sắp xếp.

- Suppose the DVDs has a different ordering rule from the other media types, that is by title, then
decreasing length, then cost. How would you modify your code to allow this?
    Answer: Ta có thể override phương thức compareTo() trong lớp DigitalVideoDisc.
    @Override
public int compareTo(Media other) {

    DigitalVideoDisc dvd = (DigitalVideoDisc) other;

    int result = this.title.compareTo(dvd.title);

    if (result != 0) {
        return result;
    }

    result = Integer.compare(dvd.length, this.length);

    if (result != 0) {
        return result;
    }

    return Float.compare(this.cost, dvd.cost);
}
